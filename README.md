# Documentation for CSCI490 Capstone

## How to Run

- The following programs have been run on Python 3.10.12 and wsl version 2.6.3.0
- `pip install -r requirements.txt` — Install required dependencies
- `python3 split_generator.py` - will use finish_time_matrix.csv for times
- `python3 train_model.py` - uses synthetic times to train model and output graph / save model

## Helpful Commands

- `sudo apt install python3.10-venv` - Install venv for virtual enviroment
- `python -m venv venv` — Create virtual environment  
- `source venv/bin/activate` — Activate virtual environment
